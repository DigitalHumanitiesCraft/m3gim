### Shared query, evidence and interaction contract

1. `recordsFor` remains the single resolver of the active document set. Basic facets keep OR within a family and AND across families. The sidebar names these combinations. Typed predicates add entity-with-role, deliberate inclusive/exclusive set intersection and selected source-document subsets. U1 defines their small tagged state representation, immutable normalization, deterministic ordering/serialization and structural equality. Logically identical updates produce no dispatch or history entry; the current shallow array comparison is insufficient for object predicates. Predicate evaluation, filter state, removable chips, URL parsing, serialization and record-navigation widening are implemented together. Views never apply an invisible second document filter. Unsupported or malformed new predicates must produce an explicit recoverable state rather than silently broadening a query.
2. A bound-role predicate carries the entity family, original facet value and recorded role key, retaining its matching source references. For a place, the matched row binds place and place role; for a person or institution, the recorded agent/subject entry binds entity and agent role. Separate entries of one record cannot supply the two halves. In the new controls, choosing a role for a selected typed entity creates this bound predicate regardless of which control was chosen first; several selected entities/roles match at least one permitted entity-role pair in a single entry. A raw text query is never interpreted as an entity identity. Existing unbound entity-plus-role URL queries remain explicitly labelled document co-occurrence and can be converted deliberately; they must not acquire a different meaning silently. Work, institution, person and place combinations without a recorded binding are labelled as document co-mentions. Stage parts retain the existing explicit/derived/unbound distinction. No automatic identity merge or occurrence reconstruction is introduced.
3. Extract the shared place-evidence projection from `views/karte-data.js` into a DOM-free data module with a name that describes place statements. Preserve E-294 source identity and all 652 current statements. Keep geographic placement enrichment separate from statement matching. Reuse the projection in Orte, the place register and dashboard. The place register retains its 102 raw `store.locations` entries and original identities; the 91 city groups belong to the Orte/map presentation. Sharing evidence must not collapse addresses, variants or register membership.
4. Every aggregate contains a stable key, display label, complete distinct `recordIds`, counting unit, denominator definition, dimension witnesses and a selection/filter descriptor. Dimension witnesses identify the original entity/type/relationship entries; primary-anchor bins retain the anchor's source. Use available source cells or the original record/property reference and name absent provenance without inventing it. A source-statement aggregate additionally contains its complete source-reference set. Derive the displayed number from the set for that unit. Repeated graph paths cannot multiply evidence; distinct source rows remain distinct. A filter's result and the documents advertised by its action must agree, subject only to the explicitly labelled undated time-window behaviour below. The query result separates document membership from its matching source witnesses. After a document qualifies, panels show its complete task-appropriate context by default and mark the matching witnesses. A witness-only display would require an explicitly labelled local mode; it cannot be an invisible second cut. Place/own-role cells and Sankey bands count their concrete statements; co-mention cells carry the separate supporting entries of both sides rather than a fabricated joint statement. Detail and export distinguish matching evidence from further context in those documents.
5. One visible search input serves Bestand, all four registers, Chronik, Orte, Netzwerk and Dashboard. It occupies a shared search row immediately above the common filter strip and stays available when the filter drawer is collapsed. Input is a local query draft; typing changes neither the cut, chip strip, URL nor history. Enter with no active suggestion commits free text through the existing normalization/search rules and exposes it as a removable filter. A click or Enter on an active combobox option selects that typed suggestion, applies its entity facet and clears only the draft, preserving previously committed filters. Suggestions show family and distinct-document count and use `{family, rawValue, label}` identities. Q-IDs provide authority links, not replacement keys for distinct recorded variants. Document suggestions show their signature/title and stable record ID; selecting one commits an exact document-subset filter. Their separate `Dokument öffnen` action navigates to the complete record while preserving the committed cut. Suggestions are calculated from the immutable base under committed remaining filters and never under the uncommitted draft as an additional document restriction. Removing a filter must restore eligible suggestions. Suggestion selection commits only the filter; a separately labelled open/focus action sends typed navigation context to a register entry or map point. An exact free-text match never changes mode automatically. Remove the local register and place lookups and all per-facet text inputs. Complete facet values and suggestions remain reachable by expansion/paging, including rare entries among the current 517 person and 248 institution names. Korb remains the explicit saved collection and information pages keep their present scope; they gain no input that cuts nothing.
6. Shared filter order, family icons, count labels and chip semantics remain identical across research views. Diagram choice, sorting, grouping, drill-down path and map viewport belong in the visualization header or drawing controls. The shared sidebar contains document restrictions and a complete role inventory, including event/date roles without a place as well as place and agent roles. Stage parts remain a separate concept. Source values without a display label or role remain reachable with an explicit missing-label/missing-role presentation. Internal selection uses a native button, an explicitly labelled action changes filters or navigates, and external Wikidata links remain independent targets. Keep complete titles, source signatures and substantive caveats; technical sheet/row labels stay in data and export under E-285.
7. Hover/focus previews a mark. Click replaces the current evidence selection and highlights the same documents in the companion panel while preserving its full context and scales. Explicit accessible add/remove actions build a union of selected marks, deduplicating both document IDs and source witnesses; a text label names this OR combination. Intersection is offered through explicit all-of/UpSet operations rather than inferred from clicks across panels. Selection opens the existing responsive detail component. Filtering is an explicit action. Changing a chart keeps the active document cut and valid selection; a filter change clears or recomputes selection without retaining invisible IDs. Empty and zero-result states carry a complete explanation of the active cut.
8. The existing primary document anchor remains the shared time axis. A temporal brush initially selects dated documents. Its separate `Zeitfenster anwenden` action names the undated context retained by the common year filter before applying it. An exact document-subset action, where offered, must preserve precisely the selected IDs. This increment's time chart counts documents by their primary anchor. A second quantitative statement-date mode is deferred; source-statement dates remain available in detail and Chronik without filling them from document anchors. Qualified, partial and ranged dates retain their interpretation in detail; ranges do not create a repeated document count in every spanned year. Any later statement-date chart needs a source-statement unit and distinct-document coverage, with explicit multiple-bin membership instead of adding its counts to the primary-anchor series.
9. Keep local UI state per mounted view and per dashboard panel. Reuse the shared router and filter serialization for reload, deep links and browser navigation. Store chart choice, dimensions, measure, grouping, sorting and a treemap drill-down path as separate `viewParams`, namespaced by stable panel IDs. Transient hover, uncommitted evidence selection and geometric map pan/zoom remain local. The router remains the only writer of addresses and retains its current `replaceState` treatment of routine filter updates. Separate application controls labelled `Filter rückgängig` and `Filter wiederherstellen` record exactly one step per committed suggestion, free-text submission, chip change or explicit filter action. Continuous range input commits at its end/change; keystrokes, hover and pan/zoom create no steps. Replay uses the same normalized mutation path without recording another step. Browser back/forward restores actual navigation entries and remains distinct from the filter-history stack. Local focus/drill-down has its own visible return to overview. A comparison reference contains an immutable filter definition, resulting IDs and dataset fingerprint; the active cut remains the single live selection. Replacing it from a reference is explicit. A changed dataset requires recomputation with an identified change, never a silently reused reference.

### Orte target

The place navigator shows name, distinct-document count and missing-location status in approximately 240–280 pixels on wide hosts. It can be collapsed; its complete contents remain reachable even when coordinates or geometry are absent. The map receives the remaining width. The common filter drawer and navigator must not force a four-column layout on smaller hosts.

Clicking a place in the navigator or map selects the same group, centres its point after the detail panel has obtained its final width and opens its evidence. Preserve an already useful zoom; only increase a very broad overview to a bounded regional view. Never imply street-level coordinate precision. Missing coordinates open the evidence with an explicit spatial limitation. The fit-all action, keyboard navigation and close/return behaviour stay available. A resize, chart switch or detail close must not repeatedly recenter or refit the map without a new spatial selection.

The detail first gives the selected place's distinct-document count, place-role distribution and coverage of explicitly dated statements. Full evidence follows, grouped for reading by role and recorded date. Identical displayed assertions may share a heading, but every source record and independent source row remains accessible and counts retain their stated unit. Document date, primary time anchor, statement date, original wording, caveats and coordinate provenance remain distinct. Related works, actors and institutions appear as labelled document co-mentions with their supporting records. Place filtering and transfer to Chronik remain explicit actions.

Use the shared detail geometry initially. Any wider detail option is added through the common component and scoped to hosts that have the space; it requires checking every existing consumer. On narrow hosts use the existing native modal detail and a collapsed navigator instead of squeezing the map and sources into narrow columns.

### Dashboard visualization contract

The navigation label becomes Dashboard and the canonical internal view key/hash remains `statistik`. Two panel headers expose independent view choices. Initial content is a document-type treemap and a work-by-document-type matrix. A panel has one task-specific grouping control set and a declared unit. One dashboard-wide selection controller owns exactly one `createSelectionDetail` instance; panels supply evidence and trigger descriptors. Panel unmount removes only its own listeners/observers. On narrow workspaces both panels remain available in a stacked layout. Opening details must leave two readable panels, stacking them according to remaining container width; the common source panel/modal supplies details instead of a third permanent chart column.

| Panel | Supported dimensions and measure | Exploration and required evidence |
|---|---|---|
| Treemap | Hierarchical document types, counted as distinct documents. Direct assignments to a parent occupy a separately labelled residual leaf; missing type has an explicit leaf. | Semantic zoom into a category with a breadcrumb and return. Selecting a leaf or branch exposes its complete ID set. Children partition their parent without counting the parent's direct assignments or descendants twice. The flat demonstrator is replaced by this hierarchy. |
| Matrix | Document type/time against work, composer, stage part, person, institution, place or country; work against institution, composer or stage part; place against its own place role; agent against its own agent role. A small supported-pair registry distinguishes recorded/derived binding from co-mention. Composer membership follows the work's recorded composer property. Work/part membership uses the curated association or a separately marked single-work derivation; unbound/multi-work parts remain explicitly unassigned. | Switch/swap compatible dimensions, sort and select rows, columns or cells; show counts or explicitly labelled row/selection shares. A labelled local focus enlarges chosen rows/columns and returns to the full matrix without changing the cut. Derived and recorded work/part cells can be inspected separately. Parent/child document types are shown at one chosen level. All rows remain reachable through expansion/paging. Cell details expose complete backing IDs and dimension witnesses. |
| Time distribution | Distinct documents by primary-anchor year, five-year group or decade; optional disjoint document-type stacks or small multiples for selected works/institutions. | Brush a period, adjust grouping and inspect dated/undated coverage. Same-scale comparisons name their denominator. Selecting a bin never counts a document as several realized appearances or turns a source interval into continuous activity. |
| Place-role Sankey | Recorded place statements over document type, place role and place; optional enriched country where available. Default is type to role. The measure is source statements, with distinct-document coverage alongside. | Select a node, band or supported full path; a labelled local branch focus expands its categories with a return to overview. Labels describe place evidence, with no travel routes, stays or performed-event counts. |
| UpSet | Overlapping document sets defined by a small user-selected collection of typed entities or supported facet conditions. | Show intersection membership and size. Inclusive means at least the checked sets; exclusive means exactly the checked sets among the displayed sets. A labelled local focus expands chosen combinations, with all remaining combinations and a return to overview reachable. Details expose every backing record. Applying an intersection preserves its full definition across views, reload and export. |
| A/B dot comparison | Works, composers, places, institutions or disjoint document types against a pinned reference A and active selection B. Count or within-selection share. | Pin/replace/clear A, sort by difference and select one side or shared records. Focus selected categories locally and restore the full overview. Show both denominators and overlapping membership. Empty denominators yield an unavailable share. Reference data outside B remains explicitly labelled and cannot silently change the active cut. |
| Place map | Reuse the Orte point-map component and the same source-backed groups. | Pan, zoom, fit and select a place to coordinate with the other panel. Count missing coordinates and provide access to their sources. The dashboard does not create a second geographic projection or deduplication path. |

Use the existing local D3 and DOM/SVG primitives. Add a pinned local Sankey module only if the existing library cannot supply its layout; retain its licence. Chart-library internals do not determine counting or evidence identity. Labels, units and accessible values accompany colour. Fixed categorical mappings do not change when a cut is filtered. Financial distributions and actual mobility routes remain outside this dashboard scope because their comparable units and historical bindings are not established.
